# Legado — o projeto de 2017

As imagens desta pasta eram parte do app original de MBA, apresentado em
novembro de 2017.

`ligada.jpg` e `desligada.jpg` **eram a interface inteira**: um `ViewSwitcher`
alternava entre as duas conforme chegasse `"1"` ou `"0"` no tópico `led`, e
tocar na imagem publicava o valor invertido.

As demais (`android*.png`) eram material da apresentação sobre Android Things e
IoT.

O código original está preservado no histórico do Git — `git log` mostra os dois
commits de 2017. A análise do que ele fazia bem e mal está em
[../ANALISE.md](../ANALISE.md).
